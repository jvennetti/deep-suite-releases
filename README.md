# DeepSuite releases

Installers for DeepBoard and DeepScore (Windows and macOS). Download page: https://deep-suite.pages.dev

Each release carries six assets: DeepBoard-Setup.exe, DeepScore-Setup.exe, DeepBoard-Windows-portable.zip, DeepScore-Windows-portable.zip, DeepBoard-macOS.dmg, DeepScore-macOS.dmg. The apps are unsigned: macOS asks once for Open Anyway in System Settings, Windows shows SmartScreen once.
